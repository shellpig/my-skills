# FACS 動作單元（AU）：輔助校準

FACS（Facial Action Coding System）把表情拆成可被觀察的肌肉動作單元。它不是情緒標籤，而是定位臉上發生了什麼。

**最穩定的寫法**：自然語言寫看得見的動作 ＋ AU 與強度做輔助校準。先描述，再校準，不要只丟一串編號——模型不一定能穩定解析所有 AU，同一個 AU 在不同組合下意義也不同（AU4 配咬牙＝憤怒；配目光下落、嘴角下沉＝痛苦）。

## 常用 AU

| AU | 動作 | 常見含義 |
|---|---|---|
| AU1 | 眉毛內側抬起 | 悲傷、擔憂、懇求 |
| AU2 | 眉毛外側抬起 | 驚訝 |
| AU4 | 眉毛下壓、聚攏 | 壓力、憤怒、專注、痛苦 |
| AU5 | 上眼瞼抬起 | 驚恐、震驚、威脅 |
| AU6 | 臉頰上提 | 真笑（配 AU12） |
| AU7 | 眼瞼收緊 | 壓抑、審視、忍耐 |
| AU9 | 皺鼻 | 厭惡 |
| AU12 | 嘴角上拉 | 笑 |
| AU15 | 嘴角向下 | 悲傷、失望 |
| AU17 | 下巴抬起並繃緊 | 忍住哭、倔強 |
| AU23 | 嘴唇收緊 | 壓住怒氣 |
| AU24 | 雙唇相壓 | 克制、不說 |
| AU25／AU26 | 嘴唇分開／下顎張開 | 爆發、吸氣、說話開始 |
| AU43 | 閉眼 | 承受、迴避 |

## 強度 A–E

A 剛剛能察覺 · B 輕度 · C 明確可見 · D 強烈 · E 接近極限

## 時間結構

**Onset**（動作開始）→ **Apex**（達到峰值）→ **Offset**（逐漸消退）。寫出每段落在哪一秒、被哪句話觸發。

## 範例：忍住 → 失控 → 重新控制

> 一個人憤怒，不應該從第一幀就把所有肌肉拉到最大。先讓 AU4 眉毛下壓、AU7 眼瞼收緊、AU23 嘴唇收緊；說到某個刺激詞時，AU25 和 AU26 才突然增強，讓嘴唇分開、下顎張開，形成短促爆發；說完以後再迅速減弱。

## 觀察方法（先看見，再命名）

把臉拆成五個區域：眉毛、眼睛、鼻翼、嘴唇、下巴。只回答四件事：

1. 哪裡在動？
2. 往哪個方向？（向上、向下、向內、向前）
3. 動作有多強？（剛能察覺、明確可見、接近極限）
4. 被哪句話觸發？（綁定具體台詞與秒數）

流程：普通話描述 → AU 校準 → 綁定秒數和台詞。
