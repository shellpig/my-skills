# 話輪：讓對白像兩個人在說話

「越規範，越不像人在反應」。台詞清晰、準確、輪流接話，結果是兩個人輪流完成任務，而沒有真正接住對方。

## 錯誤寫法

```
角色 A 先完整說完台詞，角色 B 等 A 結束後準時開口，回應上一句。
每句對白都清楚、完整、準確，不允許停頓、搶話或改口。
```

## 要設計的四種話輪

| 類型 | 意思 | 寫法要點 |
|---|---|---|
| 搶話 | 我不能讓這句話繼續 | 寫出搶入時對方停在哪個音、口型停在哪 |
| 插不進 | 想說但沒有空隙 | 寫出張嘴、吸氣、又閉上 |
| 重疊 | 兩人同時在說 | 給重疊長度（約 0.1–0.3 秒）與誰先退讓 |
| 沉默 | 我暫時找不到一種方式讓這句話不傷人 | 寫出沉默時身體在做什麼 |

## 觸發詞

每一次搶話都要由某個詞觸發，並寫出對方「聽見了什麼、判斷了什麼」：

- 她聽見「我處理得來」就判斷他又要收掉話題，在尾音未落時搶入。
- 他聽見自己被說成「逃避」，本能地連續否認「我沒有、我沒有」。
- 她看到他第二次卡在「爸——」，才放軟語氣接過話頭。
- 他直到聽見「你一個人扛」才停止改口，第一次說出完整的一句——不是辯解，而是想讓她別自責。

一個詞可以奪走原本的話語權；另一個詞可以讓破碎的句子重新完整。

## 重疊規則（可直接寫進提示詞）

- 雙方不整齊輪流說話：一方未說完，另一方溫和搶入；有人想插話卻插不進；聲音短暫重疊後有人退讓。
- 每次重疊約 0.1–0.3 秒；先進入者不能突然靜音，後進入者也不能像等待輪次。
- 重疊時保持說話人、方位、口型準確；兩張嘴按各自台詞獨立運動，聲音空間位置與人物方位一致。
- 明確寫出被打斷的句子不要自動補完。
