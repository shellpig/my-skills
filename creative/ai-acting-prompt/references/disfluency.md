# 言語不流暢（Speech Disfluency）

語言想繼續，情緒卻堵住出口。口吃、重複、沉默、自我修正只是不同的外顯結果——不是人物一緊張就隨機結巴。

## 先問：人物此刻做不到什麼？

| 心理障礙 | 外顯形式 |
|---|---|
| 羞恥／內疚，無法開始 | 啟動失敗、口吃 |
| 害怕被誤解，試圖校準 | 重複、重音 |
| 真相太殘酷，無法繼續 | 沉默、失敗吸氣 |
| 想隱藏真正意圖 | 說到一半改口（自我修正） |

## 把失敗寫在最難面對的詞上

通常是代詞（"I"／我、你）、名字、連接詞（because、but、但是我）。中文可以是「你」「我是」或對方的名字。

## 寫成身體動作，不是重複字

| 部位 | 寫法 |
|---|---|
| 口型 | 口型已經形成，聲音仍未出現 |
| 呼吸 | 吸氣失敗、短促吸氣；不是機械停頓 |
| 喉嚨 | 喉結輕動、吞嚥，隨後吞回或改換句子 |
| 分布 | 困難集中在同一類詞上，不要平均撒在整句 |

只寫「他結巴地說 I-I-I」，很容易變成喜劇口吃。

## 範例

> 她每次要說「我」都先停一下：嘴唇已經分開，聲音晚了半拍才出來。第一次「我……」後吸氣吸到一半就斷掉；第二次直接改口成「反正」；第三次低頭盯著杯子，才把「我其實很怕」完整說出口，說完立刻抿住嘴。

搶話必須由情緒觸發；所有停頓都必須像人物正在尋找語言，而不是畫面卡頓。
