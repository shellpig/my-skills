# 骨架範例：30 秒雙人情感對白

原創示意場景：醫院走廊，姊姊得知父親病情惡化，弟弟一直瞞著她。實際使用時替換角色、場景與台詞。完整版本通常 3,000–4,000 字，以下只展開到足以看出結構。

```
生成一支 30 秒、寫實電影質感、原生同步中文對白的雙人劇情短片。

【全局設定】16:9 橫屏，24fps，輕微膠片顆粒，自然主義風格。深夜醫院走廊，
日光燈偏冷、局部閃爍，牆面淺綠，遠處護理站虛化。保留皮膚紋理與黑眼圈，無磨皮。
遵守 180° 軸線：姊姊始終在左、弟弟在右。鏡頭近乎固定，輕微手持呼吸感，全部硬切。

【人物與表演】
姊姊：32 歲，……；聲線清亮但越說越低。她要的不是道歉，而是逼弟弟承認他一個人扛了多久。
弟弟：27 歲，……；聲線沙啞、語速偏快。他一直用「沒事」「我處理得來」把話題收掉，
因為只要說出真實情況，他就撐不住。
兩人不整齊輪流說話：有人搶話、有人插不進、聲音短暫重疊後有人退讓。

【表演控制原則】
弟弟的阻力是「維持正常」：每次快要說到病情，就改口去講手續和費用。
困難集中在「爸」這個字：口型已形成，聲音沒出來，吞嚥一次後改成「他」。
姊姊的阻力是「不要在他面前哭」：怒氣先撐著，眼眶到第 18 秒才開始濕潤。
話輪：姊姊聽見「我處理得來」就判斷他又要收掉話題，在尾音未落時搶入；
弟弟聽見「你一個人」才停下改口，第一次說出完整的一句話。重疊約 0.2 秒，先說的人不突然靜音。

【人物與畫面連續性】
兩人臉型、服裝、髮型、濕潤程度跨鏡頭一致。弟弟眼下的疲憊從第一幀就在；
姊姊的眼淚逐步積聚，到鏡頭二結尾才有一滴落下。切鏡只改景別，不改站位和手部狀態。

【鏡頭一｜0.0–12.0 秒】50mm 雙人中景，姊左弟右，相距一步。
0.0–3.0：弟弟低頭滑手機看繳費單，語速偏快地說：「手續我都辦好了，你不用——」
          姊姊雙手抱臂，指尖壓進袖子。
3.0–6.0：姊姊在「不用」尾音未落時搶入，聲音不大但很硬：「辦多久了？」弟弟的嘴還停在「用」的口型。
6.0–9.5：弟弟抬眼不到半秒又看回手機：「就……爸——」口型停住，吞嚥，改口：「他最近比較常住院。」
9.5–12.0：姊姊沒有回答，眉毛內側慢慢抬起，抱臂的手鬆開又抓緊。
……

【鏡頭二｜12.0–30.0 秒】……（每 2–4 秒一拍，寫到結束狀態）

【聲音】只有兩人原聲對白、日光燈電流聲與遠處推車聲；無背景音樂、無字幕。
```

## 拍的檢查

每一拍都要能填滿：時間碼／說話目標／原句＋觸發詞／可見反應／聲音動作／話輪＋聽者反應。填不滿的拍，模型就會自己補——通常補成擺表情。
